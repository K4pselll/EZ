# EZ Terminal

**EZ Terminal** is a lightweight CLI tool written in C# (.NET) designed to automate routine operations (such as Git commands) and support custom extensibility via `.EZPG` plugins.

---

## 🚀 How It Works

EZ Terminal supports two execution modes:

1. **Interactive Mode**: Launch `EZ` to start an interactive shell session:
   ```bash
   EZ
   EZ> push
   EZ> help
2. **PRERELASE**
